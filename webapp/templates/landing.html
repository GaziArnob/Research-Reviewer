Built for responsible reviewing

Reviewing is a confidential duty and venues have rules about AI. The product is designed around that.

{{ icon('shield') }} Venue AI rules are enforced

ICML, ACL Rolling Review, CVPR and IEEE forbid AI-written review text. For those venues the form hides everything a language model wrote and keeps only rule-based checks and verified quotes.

{{ icon('lock') }} Private by default

The PDF is deleted after processing. The language model runs locally. Online checks send only the title, one abstract sentence and reference titles, and can be turned off.

{{ icon('alert') }} No scores unless you ask

On a 20-paper benchmark, the local model's scores did not track human reviewers, so ratings and recommendations are never filled in for you.

{{ icon('user') }} A human approves

Nothing is final until a named reviewer signs off, and every action is written to an audit trail.
