Convert to a venue template

For authors: turn your own manuscript PDF into the layout of a conference or journal.

Up to {{ max_mb }} MB. Processed in memory and never stored.

What you get

  • main.tex: sections, abstract, numbered citations as \cite, the reference list, in the venue's preamble.
  • images/: embedded bitmap images, placed in the figures when each page has as many images as captions.
  • main.docx and a CONVERSION_REPORT.md that lists everything to check.

What it cannot do

  • Equations, table contents and vector figures are not recovered from a PDF: you get placeholders or plain text.
  • Text after the reference list (appendices) is not converted.
  • The LaTeX is not compiled here, and each venue's style file must be downloaded from the venue.
  • Page limits are only estimated. Check the PDF you compile.

Templates

“Partly verified” means some rules were read from the official page and the rest (class options, style file names) were not. The report lists which is which.
